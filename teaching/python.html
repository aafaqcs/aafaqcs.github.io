WEEK 01Why Python, how Python runs programs, and installing Python9 questions
  1. Install Python on your own machine. Record the output of python --version and where python (which python3 on macOS).
  2. In the interactive prompt compute 3*2, 7/2, 7//2 and len('engineering'). Which results would differ in C?
  3. Write hello.py in Notepad (or TextEdit) and run it from the terminal. Then deliberately save it as hello.txt; can python hello.txt still run it? Why?
  4. Run hello.py in IDLE with F5, then type total in the Shell. Explain why it works.
  5. Create a Jupyter notebook lab3.ipynb with a Markdown title, a cell setting x = 10, and a cell printing x * 2. Change x to 99 in the first cell without re-running it and run the second cell. What prints, and what does Restart & Run All print?
  6. Create a PyCharm project with a venv, run hello.py, and step through the loop in the debugger. Write down the values of total after each iteration.
  7. In VS Code, open your lab folder, select the interpreter, and run hello.py using (a) the Run triangle, (b) Shift+Enter on the loop only, (c) F5.
  8. In VS Code create a notebook, select a kernel, pip install numpy if needed, and run import numpy as np; print(np.arange(10).mean()).
  9. Deductive: A friend’s import numpy works in the terminal but fails in VS Code. Give two possible causes and the one line of Python that helps tell them apart.
WEEK 02Decisions and loops5 questions
  1. Read a number and print whether it is positive, negative or zero.
  2. Check whether a year is a leap year.
  3. Print the multiplication table of n using a for loop.
  4. Find the sum of the digits of a number using a while loop.
  5. Print the first 10 Fibonacci numbers.
WEEK 03Functions5 questions
  1. Write is_prime(n) and use it to print all primes below 100.
  2. Write a function that returns the largest of three numbers without using max().
  3. Write recursive functions for factorial and for the nth Fibonacci number.
  4. What happens when a function assigns to a global variable without the global keyword? Explain.
  5. Write a function with a default argument and call it in three different ways.
