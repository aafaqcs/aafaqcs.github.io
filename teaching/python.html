Week 01

  • Install Python on your machine and record the output of python --version.
  • In the interactive prompt compute 3 * 2, 7/2 and 7 // 2.
  • Write a Python script that prints your name and the current date.
  • List the differences between a compiler and an interpreter.

Week 02

  • Read a number and print whether it is positive, negative or zero.
  • Check whether a year is a leap year.
  • Print the multiplication table of n using a for loop.
  • Find the sum of digits of a number using while.

Week 03

  • Write is_prime(n) and use it to print all primes below 100.
  • Write a function that returns the largest of three numbers without using max().
  • Write recursive functions for factorial and Fibonacci numbers.
  • Explain what happens when a function assigns to a global variable without the global keyword.
